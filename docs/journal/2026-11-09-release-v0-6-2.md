Cut v0.6.2 with the fixes merged since v0.6.1, as [Maintain the repository](../how-to/maintain.md)

## What was done

- Since v0.6.1, on `main`:
  - [#94](https://github.com/fedeam/kausa/pull/94): with `replicaCount: 2`, the `lease error`
    hint on a `404` names the deploy tools that skip Leases, Argo CD among them, and [Install
    with Helm](../how-to/install-with-helm.md) gives the Lease to create once (issue
    [#79](https://github.com/fedeam/kausa/issues/79)).
  - [#97](https://github.com/fedeam/kausa/pull/97): an expired resource version (`410`) in a
    watch is no longer a watch error; it counts as a relist only. On k3s it made more than half
    of `kausa_watch_errors_total` for the Event watch.
  - [#96](https://github.com/fedeam/kausa/pull/96): four timing tests get longer terms, after one
    failed once under `docker build --target ci`.
  - [#98](https://github.com/fedeam/kausa/pull/98): [Memory and CPU with
    explanations](../research/2026-11-09-resource-use-with-explanations.md), measured with v0.6.1.
  - [#99](https://github.com/fedeam/kausa/pull/99): `AGENTS.md` and the architecture no longer say
    that the image and the chart are unpublished.
- Version 0.6.2 in `Cargo.toml`, `Cargo.lock` and the chart, with the changelog's Unreleased
  entries under `[0.6.2] - 2026-11-09`. The README, `SECURITY.md`, the front page, the command-line
  reference and the install guide name v0.6.2. Nothing to change in values or permissions.
